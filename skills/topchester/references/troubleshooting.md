# Troubleshooting

Start with `topchester info`, `topchester kb status`, and the newest `.agents/topchester/logs/topchester.log`. Saved sessions live below `.agents/topchester/sessions/`.

A missing project KB affects project context but should not prevent Topchester product help. A selected config profile can be shadowed when both `--config` and `TOPCHESTER_CONFIG` are present; the CLI selection wins.
