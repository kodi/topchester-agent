# Commands

Use `topchester` for the TUI and `topchester run "prompt"` for one non-interactive request. Project knowledge commands live below `topchester kb`: `init`, `sync`, `dry-run`, `status`, `search`, `context`, and `reset`.

Use `topchester info` for cheap configuration and local-state diagnostics. Use `/skills`, `/skills inspect <name>`, `/skill <name> ...`, or `@skill-name` for explicit skill activation.
